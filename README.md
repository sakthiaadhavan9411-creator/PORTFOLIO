# Jack -- 3D Creator Portfolio

A dark-themed 3D creator portfolio landing page built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Sections

1. **Hero** — full-screen intro with a magnetic-hover portrait and gradient headline.
2. **Marquee** — two rows of project preview GIFs that scroll horizontally based on page scroll position.
3. **About** — scroll-revealed character-by-character bio text with decorative 3D icons in the corners.
4. **Services** — a numbered list of five services on a white panel.
5. **Projects** — three sticky, scale-stacking project cards.

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser.

## Build for production

```bash
npm run build
npm run preview
```

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion (scroll-driven animation, sticky card stacking)
- Lucide React (icon set, available for future use)
